# Lisp

Le but de ce laboratoire est de mettre en pratique votre compréhension de la conception et l'implémentation des langages de programmation, notamment l'analyse lexicale, les expressions régulières, la tokenisation, l'analyse syntaxique, les grammaires hors contexte et le parsing, à travers un problème de programmation portant sur le langage fonctionnel Lisp.

## Notation

La notation du laboratoire est basée sur les critères suivants:

* __Fonctionnalité__: Le code fonctionne en toute circonstance, répond correctement aux exigences du sujet et produit les résultats attendus.
* __Efficacité__: Le code utilise des algorithmes et des structures de données adaptés pour garantir de bonnes performances.
* __Lisibilité__: Le code est clair et simple, bien indenté et facile à comprendre grâce à des noms explicites et des commentaires pertinents.
* __Modularité__: Le code est structuré logiquement, organisé en modules et fonctions indépendants, facilitant la réutilisation et la maintenance.
* __Style__: Le code respecte le style de programmation du langage, exploite les fonctionnalités disponibles et intègre les concepts propres au paradigme.

La note du laboratoire est calculée selon la formule suivante, chaque critère contribuant pour un maximum d'un point:

```math
N = 1 + F_x + E_x + L_x + M_x + S_x
```

où $F_x$, $E_x$, $L_x$, $M_x$ et $S_x$ représentent l'évaluation de votre code selon chaque critère respectif. 

## Livrable

Le livrable pour ce laboratoire est un programme implémenté avec le langage de programmation de votre choix, organisé en autant de fichiers que nécessaire. Le travail soumis doit être entièrement personnel et original. L’utilisation de la bibliothèque standard du langage ainsi que d’assistants de codage est autorisée, pour autant que ceux-ci s'appuient uniquement sur les concepts admis pour ce travail. En revanche, toute communication avec des personnes tierces ou tout acte de plagiat est strictement interdit. De telles pratiques constituent une violation de l’intégrité académique et seront signalées.
